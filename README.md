Journeys

A SwiftUI app for tracking train journeys, collecting commuter pass stamps, and building travel streaks. Create custom rail operators, start timed journeys, and watch your stats grow.

Requirements

iOS 17.0+
Xcode 15+
Swift 5.9+

Setup and testing

Clone the repository
Open in Xcode 15 or later
Build and run on an iOS 17 simulator or device
