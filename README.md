# 🚋 Journeys
A SwiftUI app to make studying more fun by counting your focused sessions as train journeys!

## 🚏 Features
- Focus timer with stopwatch and countdown modes
- Dynamic island live activity support
- Ability to build a streak by focusing for 15 minutes each day 
- Lots of customizability
- Detailed stats on your journeys

## 🛣️ Roadmap
- Add CloudKit sync when I have an iOS developer license
- Add Screen Time API to allow for apps to be blocked during focus sessions
- Add more customisation for RailPasses
- More milestones, achievements and fun secrets!

## 🎛️ Requirements

iOS 17.0+
Xcode 15+
Swift 5.9+

## 🛠️ Setup and testing

Use the prebuilt binary if you so wish and sideload with sideloadly or altstore 

OR

Clone the repository
Open in Xcode 15 or later
Build and run on an iOS 17 simulator or device (Or on macos via mac catalyst)
